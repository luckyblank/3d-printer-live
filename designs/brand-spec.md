# 头像打印机：工作台设计稿 v1

本目录为独立设计预览，不改变现有软件。全部界面数据与连接反馈均为明确标注的演示示例。

## 定位

- 用途：主播开播时持续监看和处理任务的桌面工作台。
- 观看距离：桌面屏幕约 50–80cm；基准窗口 1380×860，兼顾 1366×768。
- 气质：安静、清晰的工具界面，沿用原有温暖的打印场景。
- 容量：主页面固定一屏；长队列内部滚动；设置在覆盖式抽屉中滚动。

## 真实资产

- 应用图标：`assets/printer.ico`，来自 `build/desktop/printer.ico`。
- 场景：`assets/print-scene.jpg`，来自 `docs/screenshots/01-3d-scene.jpg`，保留原软件真实画面。
- 测试头像：`assets/avatar-atlas.png`，来自软件已有测试头像图集。对应昵称沿用 `assets/generated/avatar-names.json`，为原创虚构昵称。
- 场景内麻薯团子、蓝莓布丁、气泡水呀及分数来自现有场景截图；设计稿不代表当前实时打印状态。

## 视觉规则

- 背景 #111316，面板 #1b1e22，控件 #25282d，结构线 #303338。
- 主文字 #f1f0ed，次要文字 #a1a2a5；主操作珊瑚橙 #f37960。
- 状态绿色 #a6c9b0；本地演示使用低饱和黄 #dfbe81。
- 中文字体沿用本机 Microsoft YaHei UI / Microsoft YaHei；数字用 Cascadia Code / Consolas。
- 正文 13px，标题 16–17px，辅助信息 10–12px；按钮高 34px、工具按钮 28–32px。
- 8px 为基础节奏；面板间距 14px、外围 16px；紧凑方案相应为 10px。
- 控件圆角 7px，面板 12px；主页面以分隔线划层级，抽屉与菜单使用轻阴影。
- 交互反馈 160–180ms；遵循减少动态效果偏好。

## 信息分层

- 常驻：打印场景、场景/机位切换、暂停/继续、跳过、声音总开关、弹出画面、直播连接、概览。
- 右侧标签：队列、记录、演示，替代纵向堆叠。
- 设置抽屉：打印规则、画面、声音、连接详情。高级渲染及声音诊断默认收起。
- 更多：教程、功能介绍、语言、重启。

## 方案探索

Tweaks 内提供 A 标准工作台、B 紧凑工作台、C 画面优先，以及深灰/暖白两种配色。初稿只验证排版与主要交互，不接入真实直播或打印引擎。完整实现时需保留保存/重命名/删除机位、独立窗口接管、全部规则选项、头像导入与保存、规则图下载、声音诊断等现有能力。

## 独立画面的预览与正式开发要求

- 设计稿：弹出预览右上角显示「返回工作台」，方便评审时返回；同时支持 Esc。按钮以 `data-preview-only` 标记。
- 正式开发：直播输出小窗不显示「返回工作台」、设计示意或其他工具栏文字，保持纯场景。不可把设计稿的返回按钮带入正式直播输出。
